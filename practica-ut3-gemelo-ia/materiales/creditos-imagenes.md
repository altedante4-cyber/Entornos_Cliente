# Créditos de imágenes

Todas las imágenes son ilustraciones vectoriales originales dibujadas para esta práctica. No se reutilizaron imágenes de terceros; por tanto, no hay licencias externas que atribuir.

| Archivo | Uso | Autoría y licencia |
| --- | --- | --- |
| `imagenes/panel-gemelo-720.svg` / `.webp` | Ilustración del panel, variante para pantallas pequeñas | Creación propia para el proyecto. Licencia CC BY 4.0. |
| `imagenes/panel-gemelo-1200.svg` / `.webp` | Ilustración del panel, variante para pantallas grandes (`srcset`) | Creación propia para el proyecto. Licencia CC BY 4.0. |
| `imagenes/fuentes.svg` / `.webp` | Resumen conectado con correo, agenda y documento | Creación propia para el proyecto. Licencia CC BY 4.0. |
| `imagenes/conversacion.svg` / `.webp` | Ilustración de conversación para contacto y aviso legal | Creación propia para el proyecto. Licencia CC BY 4.0. |

Los SVG se han creado con formas y texto vectorial, sin datos incrustados ni dependencias externas. Las variantes WebP se generaron desde los SVG con FFmpeg a calidad 78 y dimensiones 720, 1200, 480 y 600 píxeles, respectivamente. La portada sirve WebP con SVG de respaldo y `srcset` de 720 y 1200 píxeles.

## Audio

`audio/pausa-gemelo.mp3` y `audio/pausa-gemelo.ogg` son versiones de una pieza breve generada para la práctica con tonos sintetizados mediante FFmpeg; sin muestras de terceros.
